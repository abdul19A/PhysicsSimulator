Description:
    This is a simple physics engine mainly focusing on forces applied by gravity, springs and rod-like objects, masses are treated like particles to simplify collision, as collision is not a main priority.
Goal:
    - establish cloth physics using springs, and pendulunm systems.
    - establish force acting particles, (gravity, thrusters .. etc)
    
Requirements:
    requires raylib.h (including rlgl.h and rlmath.h)
